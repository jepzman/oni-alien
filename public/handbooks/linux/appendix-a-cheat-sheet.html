A

Command cheat sheet

The commands from every chapter, grouped by the question they answer. Each row names the chapter that explains it; when a command surprises you, go back there.

Rule 1 · read first

On an unfamiliar or misbehaving server, run read-only commands before changing anything, and write down what you find (Chapter 1, Chapter 20).

Rule 2 · ask the process

A running program's truth is in /proc/<pid>/: its limits, open files, environment, cgroup. Not in your shell, not in the config file (Chapter 12).

Rule 3 · one change at a time

Check, change one thing with an undo ready, verify with the same measurement, note the time (Chapter 15, Chapter 20).
