B

Distributions compared

This book uses Ubuntu, and nearly everything in it works unchanged on any modern distribution: the kernel, systemd, the shell and the core tools are the same. What differs is mostly names and places. This appendix collects every difference the chapters mention, so you can read a guide written for another distribution, or move a server between them.

B.4Moving a server between distributions

When a guide or a script was written for another family, translate in this order: package names (search with apt search or dnf provides), service names (B.2), file locations (B.2), the firewall front end (ufw or firewalld, or plain nftables everywhere), and the mandatory access-control layer: on RHEL, files moved into unusual places need SELinux labels (semanage fcontext and restorecon), which is the most common reason a configuration that works on Ubuntu is refused on RHEL with a correct ls -l. A baseline script like Chapter 21's is where these differences belong, written once, rather than remembered.
