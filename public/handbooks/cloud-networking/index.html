Networking in the Cloud

From packets to landing zones

Who it's for

Developers, operations people and new cloud engineers who have used the cloud but find networking a black box. You know roughly what an IP address is; by the end you can design, build and debug a production network on AWS, and read one on Azure or Google Cloud.

How it's built

Twenty-five chapters in six parts. Part I is provider-neutral: how networks actually work. Parts II to V build a real cloud network piece by piece, with AWS as the main example and Azure and Google Cloud compared in every chapter. Part VI is about running it: troubleshooting, cost and networks as code. Every chapter ends with a lab and questions to check yourself.

The running example

The running example is Larder, the Amsterdam grocery-delivery company from the Practitioner’s Notebooks: one region in Frankfurt, three zones, dark stores on Wi-Fi and 4G, a payment provider and a warehouse system on the internet. You don’t need to have read the notebooks.

Start at Chapter 1, or read every written chapter on one page (also as a PDF). Chapters marked “coming” are planned; the topics they'll cover are listed.
