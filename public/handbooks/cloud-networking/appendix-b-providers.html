B

AWS, Azure and Google Cloud translation table

The same ideas under three sets of names. Use it to read another provider's documentation, or to move a design between clouds. The chapter column points to where each idea is explained; that chapter's “Across providers” section has the differences that matter.

Watch out

Similar names don't mean identical behaviour. A Google Cloud VPC is global, an AWS VPC regional; Azure network security groups have deny rules and priorities, AWS security groups don't. Read each row as “the closest equivalent”, then check the details.
