A

Subnet and CIDR cheat sheet

The numbers you look up most, on one page. The method behind them is in Chapter 2; the planning advice is in Chapter 10.

Rule 1 · size

A /n holds 232−n addresses. One more bit halves it; one fewer doubles it.

Rule 2 · alignment

A block starts on a multiple of its own size. 10.20.16.0/20 yes; 10.20.8.0/20 no.

Rule 3 · placing an address

Find the octet where the prefix ends, take the block size there, and round the address down to a multiple of it.

A.5IPv6 in five lines

  • 128 bits, written as eight groups of hex: 2001:db8:0:1::5; :: replaces one run of zero groups.
  • Subnets are always /64. An AWS VPC gets a /56: 256 subnets.
  • Addresses are usually global; reachability is decided by routes and firewalls, not NAT.
  • Outbound-only access on AWS: an egress-only internet gateway.
  • Most networks run dual stack for years.
