C

Lab setup and cost safety

Everything you need before the first lab, and the habits that keep a learning account from producing a surprise bill. Set it up once; every chapter's lab assumes it.

C.1A safe account to learn in

  • Use a separate AWS account for labs, never one with production or anyone else's work. With AWS Organizations, create it as a member account in a “sandbox” organisational unit (Chapter 24).
  • Don't use the root user for anything but account setup. Turn on MFA for root, create no access keys for it, and sign in through IAM Identity Center with your own user.
  • Give your lab user broad rights in the lab account only. The labs create VPCs, IAM roles, load balancers and more; least privilege comes later, in real accounts.
  • Use eu-central-1 (Frankfurt), as the labs do, or change the region everywhere consistently.

C.2Budgets and alarms first

Before any lab, create a budget that emails you when spending passes a small amount. This one alerts at half of $10 a month:

aws budgets create-budget \
  --account-id $(aws sts get-caller-identity --query Account --output text) \
  --budget '{"BudgetName":"handbook-labs","BudgetLimit":{"Amount":"10","Unit":"USD"},"TimeUnit":"MONTHLY","BudgetType":"COST"}' \
  --notifications-with-subscribers '[{"Notification":{"NotificationType":"ACTUAL","ComparisonOperator":"GREATER_THAN","Threshold":50,"ThresholdType":"PERCENTAGE"},"Subscribers":[{"SubscriptionType":"EMAIL","Address":"you@example.com"}]}]'

Replace the address with your own. Also turn on Cost Anomaly Detection in the Billing console: it notices unusual daily spend, such as a forgotten NAT gateway, within a day or two.

C.5Cleaning up

  1. Run terraform destroy in each lab folder, and read its plan: it should list everything the lab created.
  2. Delete what you created outside Terraform, such as Reachability Analyzer paths and analyses from the CLI.
  3. Look for anything still billing by the hour, in the lab region: 
    aws ec2 describe-nat-gateways --filter Name=state,Values=available --query 'NatGateways[].NatGatewayId'
aws ec2 describe-addresses --query 'Addresses[?AssociationId==null].PublicIp'
aws ec2 describe-vpc-endpoints --query 'VpcEndpoints[?VpcEndpointType==`Interface`].VpcEndpointId'
aws ec2 describe-transit-gateways --query 'TransitGateways[?State==`available`].TransitGatewayId'
aws ec2 describe-vpn-connections --query 'VpnConnections[?State==`available`].VpnConnectionId'
aws ec2 describe-instances --filters Name=instance-state-name,Values=running --query 'Reservations[].Instances[].InstanceId'
aws elbv2 describe-load-balancers --query 'LoadBalancers[].LoadBalancerName'
aws route53resolver list-resolver-endpoints --query 'ResolverEndpoints[].Id'
aws network-firewall list-firewalls --query 'Firewalls[].FirewallName'
aws cloudfront list-distributions --query 'DistributionList.Items[].Id'
    Every command should print an empty list, apart from anything you deliberately keep.
  4. Check the bill the next day in Cost Explorer, grouped by service. Network leftovers usually show up as NAT gateway, VPC (endpoints, public IPv4) or Elastic Load Balancing.

Watch out: Terraform state holds secrets

Some labs put secrets into Terraform state, such as VPN pre-shared keys (Chapter 13). Keep lab folders out of shared drives and public repositories, and delete them when you're done.

C.6If something keeps billing

  • Find it with the commands in C.5, or in Cost Explorer grouped by usage type (Chapter 23).
  • Delete it in the console if Terraform has lost track of it (a deleted folder, a failed apply).
  • Some resources take minutes to disappear after deletion: CloudFront distributions, Lambda network interfaces, transit gateway attachments. Check again later rather than deleting twice.
  • If a charge is a genuine mistake, AWS Support can sometimes help with a one-off credit for new learners; ask politely and say what you've done to prevent it recurring.
