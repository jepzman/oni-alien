✎A note from the author why this shelf exists

Your AI agent can write a saga orchestrator in eleven seconds. It cannot tell you whether you needed one.

Everything on this shelf is for that second part.

The classic books on this subject are excellent, 600 pages long and currently holding up a monitor. I wanted the same ideas in a form people finish. So there are four shapes here, sorted by how much time you have before the next meeting.

  • Ten minutes: a pattern note. One problem, one silly analogy, one diagram, and the column the agent never volunteers: what we lose.
  • Thirty minutes: a deep dive. The same pattern after it has met production. Failure drills, real numbers, and a checklist to take into a design review. There is a skim mode. I won't tell anyone.
  • A story: the practitioner's notebooks. Ana the architect and Grace the product owner join the same grocery start-up in the same month and write down what happens. It is the non-code half of the job: decisions, trade-offs, stakeholders and saying no politely.
  • Thirty seconds: a cheat sheet. For the command you look up twice a week and will look up again on Thursday.

What you get from any of them: better questions in the code review (is this idempotent? where's the timeout?), better prompts for the next ticket, and a sense of what each choice costs.

The honest origin story: I had usage left before my weekly limit reset, and wasting it felt worse than wasting snacks. So I asked the agent to help me write notes about what agents get wrong. It found this very relatable.

Read one a day. Argue with the ratings. Doodle in the margins.
by Jefrey Romel Tagunicar

?What's inside four formats, same idea

  1. A pattern note has eight sections: the problem, a real-life analogy, how it works, gains vs losses, nine ratings, common pitfalls, when to use it, and a self-check quiz.
  2. A deep dive has ten chapters: a recap of the notes, the real mechanism, failure drills, the hard problem, numbers, testing, running it, tools, a lab and a review checklist. Every chapter opens with its gist.
  3. A practitioner's note has the same eight sections as a pattern note, set inside the Larder story, plus a template to copy and a “try it” exercise.
  4. A cheat sheet is a few A4 cards: a map on top, boxed panels below, and a PDF to print.
