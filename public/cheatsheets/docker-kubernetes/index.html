Dockerfile rules

  1. Order by change rate: dependencies first, source last, so the cache works.
  2. .dockerignore .git, node_modules, .env, build output.
  3. Pin the base node:22-alpine, never latest.
  4. Run as non-root with USER.
  5. Exec-form CMD ["node","app.js"] so SIGTERM reaches the app.
  6. No secrets in layers. --secret at build, env at runtime.
  7. One process per container, logging to stdout.

Ship a version · roll backrelease

Scale

The HPA scales on CPU requests: no requests, no autoscaling.

Probes

askson failure
startuphas it booted?others wait; restart if it never passes
readinesscan it take traffic?removed from the Service; not restarted
livenessis it stuck?container restarted

Keep liveness cheap and free of dependencies: a slow database must not restart every pod.

Requests & limits

CPU over
throttled (slow, not killed)
Memory over
OOMKilled · exit 137
Guaranteed
requests = limits: evicted last
Burstable
requests < limits
BestEffort
none set: evicted first

Config & secrets

Secrets are base64, not encrypted: add encryption at rest and RBAC, or use External Secrets / Sealed Secrets. Env vars only change when pods restart; mounted files update by themselves.

Strategy, jobs & disruptions

Recreate when two versions can't run side by side. Add a PodDisruptionBudget so node drains keep enough pods up.

Status decoder

Pending
no node fits: requests, PVC, taints, nodeSelector
ContainerCreating
stuck on a volume, secret or network
ErrImagePull
wrong image / tag, or no pull secret
CrashLoopBackOff
starts, exits, retries with growing delay
OOMKilled
over the memory limit: raise it or fix the leak
CreateContainer­ConfigError
a ConfigMap / Secret or key is missing
Evicted
node ran short of memory or disk
Terminating forever
finalizers or a dead node: describe first

Stay safe

  • Check the context before apply / delete
  • kubectl diff -f k8s/ before apply
  • Generate YAML: --dry-run=client -o yaml
  • No kubectl edit in prod: git wins
  • Never :latest; pin tags or digests
  • Requests + limits on every container
  • --force --grace-period=0: last resort

No traffic? Walk the path

  1. kubectl get endpoints web: empty means the selector doesn't match the pod labels, or no pod is Ready.
  2. port-forward to a pod, then to the Service: which hop fails?
  3. DNS from inside: kubectl run tmp --rm -it --image=busybox:1.36 -- nslookup web.shop
  4. targetPort = the port the container really listens on? Ingress: describe ingress for host, path, ingressClassName, TLS secret. Still nothing? A NetworkPolicy may block it.
